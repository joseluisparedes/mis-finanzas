TIPO DE PROYECTO:
================
Aplicación web de gestión financiera personal desarrollada en React + Vite + Supabase
- Frontend: React, Tailwind CSS, Lucide React icons, Chart.js
- Backend: Supabase (PostgreSQL, Auth, Storage)
- Despliegue: GitHub Pages (https://joseluisparedes.github.io/mis-finanzas/)
- Rama principal: deploy-web-version

ARQUITECTURA DEL PROYECTO:
=========================
- src/AppSupabase.jsx: Componente principal con toda la lógica
- src/components/Auth/AuthButton.jsx: Componente de autenticación
- tailwind.config.js: Configuración de Tailwind con dark mode
- Base de datos: Supabase con tablas para gastos, ingresos, recurrentes, metodos_pago

FUNCIONALIDADES PRINCIPALES:
===========================
1. Autenticación con Supabase Auth
2. Gestión de Balance (ingresos/gastos)
3. Sección Gastos (CRUD completo)
4. Sección Ingresos (CRUD completo)
5. Sección Recurrentes (gastos e ingresos automáticos)
6. Reportes con filtros y gráficos
7. Dark mode implementado
8. Responsive design

SESIÓN 1 - IMPLEMENTACIÓN DARK MODE (Agosto 2025):
--------------------------------------------------
PROBLEMA INICIAL: El usuario reportó que el modo oscuro se veía "feo" y tenía "pésima experiencia de usuario"

ANÁLISIS REALIZADO:
- Se identificaron 50+ patrones condicionales problemáticos de dark mode
- Uso inconsistente de clases condicionales tipo {darkMode ? 'clase-dark' : 'clase-light'}
- Falta de sistema unificado de colores para dark mode

SOLUCIÓN IMPLEMENTADA:
1. Actualización de tailwind.config.js:
   - darkMode: 'class'
   - Paleta de colores personalizada:
     * 'dark-bg': '#0f172a' (slate-900)
     * 'dark-surface': '#1e293b' (slate-800) 
     * 'dark-card': '#334155' (slate-700)
     * 'dark-border': '#475569' (slate-600)
     * 'dark-text': '#f1f5f9' (slate-100)
     * 'dark-text-secondary': '#cbd5e1' (slate-300)
     * 'dark-text-muted': '#94a3b8' (slate-400)

2. Sistema de clases helper en AppSupabase.jsx:
   - cardClasses: bg-white dark:bg-dark-surface con bordes y sombras
   - textPrimaryClasses: text-gray-900 dark:text-dark-text
   - textSecondaryClasses: text-gray-600 dark:text-dark-text-secondary
   - buttonPrimaryClasses, buttonSuccessClasses, buttonDangerClasses

3. Reemplazo sistemático de patrones condicionales:
   - Eliminación de 50+ condicionales {darkMode ? ... : ...}
   - Uso de dark: prefijos de Tailwind
   - Aplicación consistente en todas las secciones

FEEDBACK DEL USUARIO Y REFINAMIENTO:
- Usuario confirmó que Balance y Reportes se veían bien
- Solicitó replicar ese estilo en Gastos, Ingresos y Recurrentes
- Se estandarizaron títulos, labels y botones en todas las secciones
