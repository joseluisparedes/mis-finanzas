TIPO DE PROYECTO:
================
Aplicación web de gestión financiera personal desarrollada en React + Vite + Supabase
- Frontend: React, Tailwind CSS, Lucide React icons, Chart.js
- Backend: Supabase (PostgreSQL, Auth, Storage)
- Despliegue: GitHub Pages (https://joseluisparedes.github.io/mis-finanzas/)
- Rama principal: deploy-web-version

ARQUITECTURA DEL PROYECTO:
=========================
- src/AppSupabase.jsx: Componente principal con toda la lógica
- src/components/Auth/AuthButton.jsx: Componente de autenticación
- tailwind.config.js: Configuración de Tailwind con dark mode
- Base de datos: Supabase con tablas para gastos, ingresos, recurrentes, metodos_pago

FUNCIONALIDADES PRINCIPALES:
===========================
1. Autenticación con Supabase Auth
2. Gestión de Balance (ingresos/gastos)
3. Sección Gastos (CRUD completo)
4. Sección Ingresos (CRUD completo)
5. Sección Recurrentes (gastos e ingresos automáticos)
6. Reportes con filtros y gráficos
7. Dark mode implementado
8. Responsive design
