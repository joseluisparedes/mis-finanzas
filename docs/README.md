# Mis Finanzas

Aplicación de gestión financiera personal desarrollada con React y Vite.

## Características

- Seguimiento de ingresos y gastos
- Categorización de transacciones
- Dashboard con resúmenes financieros
- Interfaz moderna y responsive

## Deploy

Esta aplicación está desplegada automáticamente en GitHub Pages.
